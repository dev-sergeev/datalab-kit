# Changelog

## Unreleased

- Добавлено обязательное усиленное согласование известных локальных удалений, всех Hadoop/HDFS вызовов и изменяющего/неизвестного SQL через `psql`, `beeline`, `hive`, `spark-sql`.
- Крупный красный inline-блок требует точного `yes` с отправкой; Esc/Ctrl-C отменяют, Ctrl+PgUp/PgDn раскрывают длинный вызов. Одобрение относится только к полному неизменённому вызову, без grants и второго штатного диалога.
- Усиленное согласование не обходится через YOLO, `allow` и штатные сессионные разрешения. Применимые конфигурационные `deny` и действующий Plan mode проверяются до UI и после ответа, в том числе на родительском маршруте субагентов.
- Добавлен межсессионный/межпроцессный брокер запросов субагентов к человеческому TUI/RPC endpoint; отсутствие доступной авторизации блокирует вызов.
- Добавлен независимый fail-closed bootstrap для фиксированного permission-system 33.0.5 и адаптера v1; установка настоящего npm-архива проверяет headless-защиту и несовместимое/частичное обновление.
- Shell-разбор учитывает области функций/каталогов и аргументы известных вложенных исполнителей; конфигурационный deny применяется и к восстановленной команде. `git clean` без доказанного dry-run защищён независимо от внешней настройки force; генерируемые аргументы SQL-заданий считаются неизвестными.
- Нормализованные veto учитывают явный Git work-tree и простые quoted ссылки на известные bindings; временный environment команды не подменяет уже раскрываемые argv. Эта evidence не ослабляет обязательное согласование неизвестного SQL или динамических аргументов.
- Обычный путь permission-system, непрозрачные исполняемые сценарии и явный ручной bash сохранены. Границы защиты и исключение к приоритету `allow` зафиксированы в ADR 0003.

## 0.1.3 — 2026-10-03

- Добавлены `@tifan/pi-recap` 0.4.7, `@pi-plugins/elapsed` 0.1.1, `pi-toggle-skills` 0.1.20 и `@zigai/pi-mention-skill` 0.10.4; пакеты и зависимости включены в архив набора.
- Recap по умолчанию использует Qwen без reasoning через GigaChat, включая сброс через `Use default`. Явная модель recap сохраняется; штатный таймаут 4 секунды не изменён.
- При подключении GigaChat внутри набора регистрируется публичный провайдер без переключения основной модели со стороны его standalone-расширения.

## 0.1.2 — 2026-10-01

- Возвращён штатный диалог `@gotgenes/pi-permission-system`, включая разрешение на сессию и отказ с причиной. Собственный диалог Datalab Kit удалён.
- Удалены собственные команды `/yolo on|off|status`; YOLO остаётся в штатных настройках permission-system.
- Автоматическое разрешение чтения и todo, пользовательские правила и интеграция Plan mode сохранены.
- Сборка очищает устаревшие модули диалога и YOLO при обновлении с 0.1.1.
- Добавлены проверки штатных вариантов диалога, однократного и сессионного разрешения, смены сессии и штатного YOLO.

## 0.1.1 — 2026-10-01

- Служебный todo и безопасные читающие цепочки с шаблонами файлов больше не требуют подтверждения по правилам набора.
- Добавлены сессионные команды `/yolo on`, `/yolo off`, `/yolo status`; постоянная настройка YOLO сохранена. Явные запреты и ограничения Plan mode остаются активными.
- Исправлен разбор имён файлов после `<`, которые могли скрыть изменяющую команду или опасную опцию.
- Исправлена атрибуция эффектов опасных опций и приоритет пользовательских правил в составных командах.
- Пользовательские ограничения путей проверяются для файлов, раскрытых shell-шаблонами, включая симлинки и команды после `cd`.
- Добавлены интеграционные матрицы читающих и изменяющих команд, обновление todo, проверки симлинков, режимов Plan/YOLO и смены сессии.

## 0.1.0 — 2026-09-30

- Первый публичный выпуск набора из восьми дополнений для Pi coding agent.
- Значения по умолчанию разрешают чтение и требуют подтверждения изменений; пользовательские настройки имеют приоритет.
- Plan mode контролирует допустимость операций без дополнительных подтверждений набора.
- Общий предел параллельности субагентов; GigaChat обновляется независимо от версии набора.
