# Changelog

## 0.1.2 — 2026-10-01

- Возвращён штатный диалог `@gotgenes/pi-permission-system`, включая разрешение на сессию и отказ с причиной. Собственный диалог Datalab Kit удалён.
- Удалены собственные команды `/yolo on|off|status`; YOLO остаётся в штатных настройках permission-system.
- Автоматическое разрешение чтения и todo, пользовательские правила и интеграция Plan mode сохранены.
- Сборка очищает устаревшие модули диалога и YOLO при обновлении с 0.1.1.
- Добавлены проверки штатных вариантов диалога, однократного и сессионного разрешения, смены сессии и штатного YOLO.

## 0.1.1 — 2026-10-01

- Служебный todo и безопасные читающие цепочки с шаблонами файлов больше не требуют подтверждения по правилам набора.
- Добавлены сессионные команды `/yolo on`, `/yolo off`, `/yolo status`; постоянная настройка YOLO сохранена. Явные запреты и ограничения Plan mode остаются активными.
- Исправлен разбор имён файлов после `<`, которые могли скрыть изменяющую команду или опасную опцию.
- Исправлена атрибуция эффектов опасных опций и приоритет пользовательских правил в составных командах.
- Пользовательские ограничения путей проверяются для файлов, раскрытых shell-шаблонами, включая симлинки и команды после `cd`.
- Добавлены интеграционные матрицы читающих и изменяющих команд, обновление todo, проверки симлинков, режимов Plan/YOLO и смены сессии.

## 0.1.0 — 2026-09-30

- Первый публичный выпуск набора из восьми дополнений для Pi coding agent.
- Значения по умолчанию разрешают чтение и требуют подтверждения изменений; пользовательские настройки имеют приоритет.
- Plan mode контролирует допустимость операций без дополнительных подтверждений набора.
- Общий предел параллельности субагентов; GigaChat обновляется независимо от версии набора.
