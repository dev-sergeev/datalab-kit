# Changelog

## 0.1.8 — 2026-10-21

- `@dev-sergeev/pi-gigachat` закреплён строго на `0.6.5`; совместимость Pi остаётся строго `0.85.1`.
- Источник `npm:@dev-sergeev/pi-gigachat@0.6.4`, поставлявшийся с набором 0.1.7, мигрирует на `0.6.5` с сохранением фильтров ресурсов и остальных настроек. Остальные явно выбранные версии сохраняются.
- Учтён переход upstream с `extension.js` на `extension.ts`: публичные default- и stream-экспорты собираются с набором без патчей кода GigaChat. Это сохраняет первую активацию и DataLab в изолированной установке Pi, обходя несовместимость загрузчика с глубокими импортами pi-ai и прямым native-импортом TypeScript из `node_modules`.
- Runtime-зависимости адаптера `proper-lockfile` 4.1.2 и `undici` 8.11.2 включены в архив; API установленного Pi не включаются. Если Pi пропустил кешированный источник старой версии, мастер GigaChat доступен через набор без сетевой установки при запуске.

## 0.1.7 — 2026-10-20

- Совместимость с Pi закреплена строго на `0.85.1`: peer-зависимости `pi-ai`, `pi-coding-agent` и `pi-tui` больше не допускают произвольные версии.
- `@dev-sergeev/pi-gigachat` закреплён на `0.6.4` в манифесте, lockfile и отдельном источнике Pi. Установщик больше не запрашивает `latest`; штатное обновление Pi сохраняет закреплённую версию.
- Прежняя незакреплённая запись GigaChat мигрирует на `npm:@dev-sergeev/pi-gigachat@0.6.4` с сохранением фильтров ресурсов. Явно выбранные пользователем версии и остальные настройки сохраняются.

## 0.1.6 — 2026-10-15

- В пакет включены навыки `init` и `skill-creator`, доступные во всех проектах после глобальной установки набора. Добавлены короткие команды `/init` и `/skill-creator`; явное отключение ресурсов Pi сохраняет приоритет.
- `/init` изучает проект и создаёт или актуализирует `AGENTS.md`, сохраняя существующие инструкции.
- `skill-creator` перенесён из Anthropic (`dbd4588f9e1033efb41dad4bef2f7947c8993d44`, Apache-2.0) и полностью адаптирован под Pi: создание и обновление навыков, сравнение с baseline, benchmark/viewer, обратная связь и оптимизация описания. Claude Code не требуется; Python-утилитам нужны Python 3.10+ и PyYAML.
- Новые навыки по умолчанию размещаются глобально в каталоге агента Pi; явно заданный путь важнее. Рабочие результаты не записываются в каталог установленного пакета.
- Адаптация учитывает `disable-model-invocation`, отчёты без holdout, вложенные каталоги запусков и фактическое число повторений. Viewer выбирает другой порт, если заданный занят, не завершая чужие процессы. Ошибки модели и таймауты не считаются успешными отрицательными результатами оценки.
- Добавлены проверки Python-ресурсов в CI Linux/macOS и регрессии для совместимости метаданных, отчётов и viewer. Уточнена проверка локального npm-архива для Pi 0.85.1.
- Проверка полного времени запроса `elapsed` переведена на управляемые часы вместо реальных задержек, чтобы исключить гонку первого тика на CI; код компонента не менялся.
- Короткие команды используют штатный pipeline ввода Pi: CLI дожидается выполнения и возвращает ошибку авторизации корректным exit status. Одноимённые пользовательские команды и prompt templates сохраняют приоритет.

## 0.1.5

- GigaChat загружается через штатную точку входа расширения с интерактивным мастером `/gigachat`; пользовательские подключения и настройки сохраняются. Lockfile обновлён до `pi-gigachat` 0.6.1 без изменения upstream-кода; зависимость остаётся `latest`. Прежние утверждения для 0.5.1 о встроенных моделях и автоматическом default больше не применяются.
- Добавлен отдельный провайдер `DataLab` с моделями `glm-5.2 [DataLab]` и `Qwen3.5-397b [DataLab]`, только когда `GIGACHAT_API_URL` и `JPY_API_TOKEN` обе непусты после trim. Адрес задаёт корень API, токен передаётся как Bearer без сохранения в `auth.json`; `.env` автоматически не загружается, изменения окружения требуют перезапуска Pi.
- DataLab не меняет текущую модель или сохранённые defaults, не запрашивает каталог моделей и не проверяет сервер при запуске. Ошибки сервера возвращаются при обычном запросе к модели. Решение и границы ответственности описаны в ADR 0003.

## 0.1.4 — 2026-10-14

- GigaChat загружается через штатную точку входа расширения: доступны `/login`, мастер `/gigachat`, встроенные модели и собственная политика выбора default-модели. Lockfile обновлён до `pi-gigachat` 0.5.1; зависимость остаётся `latest`.
- Recap без отдельной настройки использует текущую модель основной сессии, включая смену через `/model`; явный выбор recap сохраняет приоритет. `Use default` немедленно возвращает наследование.
- Таймаут recap увеличен до 60 секунд. Для GigaChat запросы выполняются без reasoning, если его не переопределяют параметры провайдера; thinking основной сессии не меняется.
- Автоматический recap запускается через 2 минуты бездействия вместо штатных 5 минут.
- Конфиг recap не создаётся автоматически; сохранённые настройки и авторизация не очищаются. Устаревший модуль `dist/recap` удаляется при сборке.

## 0.1.3 — 2026-10-03

- Добавлены `@tifan/pi-recap` 0.4.7, `@pi-plugins/elapsed` 0.1.1, `pi-toggle-skills` 0.1.20 и `@zigai/pi-mention-skill` 0.10.4; пакеты и зависимости включены в архив набора.
- Recap по умолчанию использует Qwen без reasoning через GigaChat, включая сброс через `Use default`. Явная модель recap сохраняется; штатный таймаут 4 секунды не изменён.
- При подключении GigaChat внутри набора регистрируется публичный провайдер без переключения основной модели со стороны его standalone-расширения.

- Добавлены проверки штатных вариантов диалога, однократного и сессионного разрешения, смены сессии и штатного YOLO.

## 0.1.1 — 2026-10-01

- Пользовательские ограничения путей проверяются для файлов, раскрытых shell-шаблонами, включая симлинки и команды после `cd`.
- Добавлены интеграционные матрицы читающих и изменяющих команд, обновление todo, проверки симлинков, режимов Plan/YOLO и смены сессии.

## 0.1.0 — 2026-09-30

- Первый публичный выпуск набора из восьми дополнений для Pi coding agent.
- Значения по умолчанию разрешают чтение и требуют подтверждения изменений; пользовательские настройки имеют приоритет.
- Plan mode контролирует допустимость операций без дополнительных подтверждений набора.
- Общий предел параллельности субагентов; GigaChat обновляется независимо от версии набора.
