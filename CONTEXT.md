# Datalab Kit

Datalab Kit — распространяемый другим пользователям набор дополнений для Pi coding agent.

## Language

**Pi**:
Pi coding agent, к которому пользователь добавляет Datalab Kit.
_Avoid_: pi без уточнения при первом упоминании

**Datalab Kit**:
Набор полезных дополнений для Pi, распространяемый как единое целое. Пользователь добавляет его к уже установленному Pi.
_Avoid_: отдельная конфигурация Pi, замена Pi

**Опасная команда**:
Команда, для которой политика Datalab Kit требует явного подтверждения пользователя из-за удаления данных, возможного изменения внешних сервисов или принадлежности к отдельно обозначенной группе команд.

**Операция чтения**:
Операция получения данных, которую политика Datalab Kit разрешает без подтверждения и которая не изменяет файлы или состояние сервисов. Чтение файлов может обращаться к любым каталогам, а запросы к сервисам автоматически разрешаются только для localhost.

**Plan mode**:
Режим исследования и согласования плана до перехода к реализации. Допустимость операций в этом режиме определяется политикой планирования, в том числе для проверок и тестов.

**Пользовательское правило разрешений**:
Явно заданное пользователем правило `allow`, `ask` или `deny` для инструмента, команды или доступа к пути. Имеет приоритет над значениями по умолчанию Datalab Kit.

**Служебный todo**:
Список задач текущей сессии Pi, используемый для планирования и отслеживания работы. Его обновление не является изменением файлов проекта или внешнего сервиса.

**YOLO**:
Штатный режим permission-system для автоматического разрешения операций, которые обычно требуют подтверждения (`ask`). Явные запреты (`deny`) и ограничения Plan mode продолжают действовать.

**Сессионное разрешение**:
Решение пользователя в штатном диалоге permission-system, разрешающее соответствующие операции до конца текущей сессии в пределах выбранного правила.
