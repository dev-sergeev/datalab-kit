# Datalab Kit

Datalab Kit — набор самостоятельных дополнений для Pi coding agent.

## Language

**Pi**:
Pi coding agent, к которому пользователь подключает дополнения.
_Avoid_: pi без уточнения при первом упоминании

**Datalab Kit**:
Набор готовых пакетов для Pi с однократной установкой одной командой. Не владеет поведением компонентов после установки.
_Avoid_: замена Pi, единое runtime-расширение

**Компонент набора**:
Самостоятельный пакет Pi из состава Datalab Kit, который пользователь независимо обновляет, настраивает и удаляет.

**Первоначальная установка набора**:
Однократное подключение отсутствующих компонентов в выбранной области установки. Завершённая установка не восстанавливает удалённые компоненты и не пересматривает пользовательский выбор версий.

**Оригинальный пакет**:
Пакет исходного сопровождающего, подключаемый Datalab Kit без изменений со стороны набора.

**Готовый форк**:
Самостоятельно распространяемый пакет с доработками оригинала, подключаемый под собственным именем форка. Доработки принадлежат форку, а не Datalab Kit.
