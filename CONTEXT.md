# Datalab Kit

Datalab Kit — распространяемый другим пользователям набор дополнений для Pi coding agent.

## Language

**Pi**:
Pi coding agent, к которому пользователь добавляет Datalab Kit.
_Avoid_: pi без уточнения при первом упоминании

**Datalab Kit**:
Набор готовых пакетов для Pi, устанавливаемых одной командой. После установки каждый пакет независимо обновляется и удаляется пользователем; Datalab Kit не изменяет исходники или поведение подключаемых пакетов.
_Avoid_: отдельная конфигурация Pi, замена Pi

**Первоначальная установка набора**:
Однократное подключение пакетов состава Datalab Kit. После него обновление или повторная установка набора не восстанавливает удалённые компоненты и не меняет самостоятельно выбранные пользователем версии.

**Оригинальный пакет**:
Пакет, распространяемый исходным сопровождающим и подключаемый Datalab Kit без изменений его исходников или поведения со стороны набора.

**Готовый форк**:
Самостоятельно распространяемый пакет с доработками оригинального пакета. Datalab Kit подключает его под собственным именем форка без дополнительных изменений.

**Опасная команда**:
Команда, для которой политика Datalab Kit требует явного подтверждения пользователя из-за удаления данных, возможного изменения внешних сервисов или принадлежности к отдельно обозначенной группе команд.

**Операция чтения**:
Операция получения данных, которую политика Datalab Kit разрешает без подтверждения и которая не изменяет файлы или состояние сервисов. Чтение файлов может обращаться к любым каталогам, а запросы к сервисам автоматически разрешаются только для localhost.

**Plan mode**:
Режим исследования и согласования плана до перехода к реализации. Допустимость операций в этом режиме определяется политикой планирования, в том числе для проверок и тестов.

**Пользовательское правило разрешений**:
Явно заданное пользователем правило `allow`, `ask` или `deny` для инструмента, команды или доступа к пути. Имеет приоритет над значениями по умолчанию Datalab Kit.

**Служебный todo**:
Список задач текущей сессии Pi, используемый для планирования и отслеживания работы. Его обновление не является изменением файлов проекта или внешнего сервиса.

**YOLO**:
Штатный режим permission-system для автоматического разрешения операций, которые обычно требуют подтверждения (`ask`). Явные запреты (`deny`) и ограничения Plan mode продолжают действовать.

**Сессионное разрешение**:
Решение пользователя в штатном диалоге permission-system, разрешающее соответствующие операции до конца текущей сессии в пределах выбранного правила.

**Провайдер GigaChat**:
Интеграция Pi с GigaChat-совместимыми сервисами, поддерживающая авторизацию и работу с моделями. Доступность провайдера для авторизации и доступность его моделей — разные понятия.

**Встроенные модели GigaChat**:
Модели, заранее включённые в состав провайдера, в отличие от моделей, выбранных пользователем из каталога конкретного сервера.

**Модели Datalab Kit**:
Заранее определённый для пользователей Datalab Kit набор моделей GigaChat. Состав набора не зависит от пользовательского окружения или каталога конкретного сервера.

**Подключение GigaChat**:
Именованное подключение к конкретному серверу с собственной авторизацией и выбранным набором моделей.

**Подключение GigaChat из окружения**:
Подключение GigaChat, адрес сервера и данные доступа которого задаются окружением пользователя, а не сохранёнными значениями. Наличие моделей в списке выбора не означает готовность подключения к выполнению запросов.

**DataLab**:
Подключение GigaChat из окружения с фиксированным набором моделей Datalab Kit. Отличается от подключений, которые пользователь самостоятельно создаёт через мастер GigaChat.

**Модель по умолчанию**:
Модель для основной сессии или резюме, используемая при отсутствии явного выбора для соответствующей задачи.

**Модель recap**:
Модель для генерации краткого резюме сессии. Совпадает с текущей моделью основной сессии, если пользователь не выбрал отдельную модель резюме.

**Глобальная доступность навыков Datalab Kit**:
Доступность навыков набора в Pi из любого каталога после глобальной установки Datalab Kit, без подключения набора к каждому проекту. Не отменяет явных пользовательских отключений.

**Инициализация проекта**:
Изучение существующего проекта и подготовка инструкций для работы агента в нём. Не означает установку или настройку Datalab Kit и сохраняет существующие инструкции проекта.
