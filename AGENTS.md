## Agent skills

### Issue tracker

Задачи и спецификации хранятся в `.scratch/<feature>/`. См. `docs/agents/issue-tracker.md`.

### Triage labels

Используются стандартные пять меток triage. См. `docs/agents/triage-labels.md`.

### Domain docs

Используется схема single-context: `CONTEXT.md` в корне и ADR в `docs/adr/`. См. `docs/agents/domain.md`.
