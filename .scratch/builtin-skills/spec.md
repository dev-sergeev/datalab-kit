# Встроенные навыки Datalab Kit

Status: accepted — пользователь подтвердил спецификацию, реализацию и полный выпуск 0.1.6.

## Цель

Добавить в Datalab Kit навыки `init` и `skill-creator`, доступные во всех сессиях Pi из любого каталога после глобальной установки пакета. Установка в каждый проект не требуется. Поддержка других агентов не входит в задачу.

## Согласованные решения

- Пользовательские явные отключения и настройки сохраняют приоритет по ADR 0001. «Всегда» означает глобальную область доступности, а не запрет отключения.
- Пользовательские команды: `/init` и `/skill-creator`. Первоначальное имя `/create-skill` заменено; совместимый псевдоним не требуется.
- В Pi штатные команды навыков имеют форму `/skill:<имя>`. Нужны также запрошенные короткие команды, работающие при стандартной конфигурации набора, где `/skill:*` скрыты из autocomplete.
- `/init` изучает текущий репозиторий и создаёт или актуализирует `AGENTS.md`: команды, структура и правила работы. Существующие инструкции сохраняются и дополняются по необходимости. Это не установка и не настройка Datalab Kit.
- `/skill-creator` создаёт и обновляет навыки; новые навыки по умолчанию размещаются глобально для Pi (`~/.pi/agent/skills/<имя>/` при стандартном каталоге агента). Явно указанный пользователем путь важнее.
- Источник `skill-creator`: Anthropic, `anthropics/skills`, каталог `skills/skill-creator`. Это заменяет ранее рассмотренный вариант OpenAI/Codex.
- Полная адаптация процесса Anthropic для Pi: создание, оценка, сравнение с baseline, просмотр результатов, итеративное улучшение и оптимизация описания. Вызовы `claude -p` и привязки к каталогам Claude должны быть заменены на рабочие механизмы Pi; установленный или авторизованный Claude Code не требуется.
- Python-скрипты сохраняются; Python 3 и PyYAML документируются как требования для соответствующих скриптов. Отказаться от них или перенести весь процесс на Node.js пользователь не выбирал.
- Сохранить Apache-2.0, атрибуцию и требуемые уведомления об изменениях. Зафиксировать исходную ревизию при переносе и включить все необходимые ресурсы в npm-архив.

## Приёмка

- Чистая глобальная установка npm-архива делает оба навыка и короткие команды доступными в Pi в разных каталогах без проектной установки.
- `/init` подготавливает инструкции в новом проекте и сохраняет существующие инструкции при обновлении.
- `/skill-creator` создаёт рабочий навык в глобальном каталоге Pi по умолчанию и учитывает явно заданный другой путь.
- Сценарии оценки и оптимизации выполняются через Pi, без Claude Code; форматы результатов совместимы с поставляемым viewer.
- Пользовательские настройки не перезаписываются; штатное явное отключение ресурсов сохраняет силу.
- Установка и обновление пакета не теряют ресурсы навыков. Проверки включают фактический запуск изменённых сценариев, а не только тесты и сборку.
- README, CHANGELOG, сведения о стороннем коде и версии пакета/lockfile соответствуют поставляемому поведению.

## Выпуск

Согласован полный patch-релиз `0.1.6` (на момент проверки локальная и опубликованная npm-версия — `0.1.5`): коммит, успешный CI Linux/macOS, проверенный npm-архив, публикация npm, проверка опубликованной версии, тег `v0.1.6` и GitHub Release. Публикация — только после реализации и проверок.
