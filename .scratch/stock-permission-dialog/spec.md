# Штатные разрешения — 0.1.2

Пользователь подтвердил упрощение: вернуть штатный диалог @gotgenes/pi-permission-system и убрать собственные команды /yolo. Управление YOLO остаётся в штатных настройках расширения.

Сохраняются автоматическое разрешение безопасного чтения и todo, приоритет пользовательских правил и делегирование допустимости операций Plan mode. Изменяющие операции по-прежнему используют штатные запросы permission-system; разрешение на сессию снова доступно.

Удаляются собственный ConfirmationDialog, адаптация настроек его выбора и сессионный YOLO. Повторная сборка старого checkout восстанавливает исходный UI upstream и удаляет устаревшие dist-модули.

Проверки: чтение/изменения, однократные и сессионные решения, смена сессии, штатный YOLO/deny/Plan, пользовательские настройки, установка и обновление npm-архива, CI Linux/macOS. Публикация версии 0.1.2, тег v0.1.2 и GitHub Release после проверок.
