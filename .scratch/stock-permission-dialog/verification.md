# Проверка 0.1.2

- `npm run build` и `npm run typecheck` прошли, повторная сборка идемпотентна.
- 36 локальных тестов поведения прошли, включая штатный диалог без пользовательских настроек и с doublePressToConfirm true/false.
- Однократное разрешение спрашивает снова; сессионное разрешение подавляет повторный запрос для соответствующего правила, но не разрешает несвязанную команду. Завершение сессии очищает разрешение.
- Матрица чтения/изменений, сотни сочетаний цепочек, todo, пользовательские правила путей/симлинков/шаблонов и Plan mode прошли.
- Штатный YOLO разрешает ask, сохраняет deny и ограничения Plan mode; собственного /yolo нет, конфиги не переписываются.
- Локальный процесс теста установки архива аварийно завершился без подробной диагностики. Полная проверка установки и обновления обязательна в CI Linux/macOS перед публикацией.
- Состав архива проверяется на отсутствие удалённых dist/confirmation.* и dist/yolo.* и отсутствие API хоста; установленный пакет проверяется на штатный /permission-system и отсутствие /yolo.
