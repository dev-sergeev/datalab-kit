# Проверка реализации

## Выполнено локально

- Node.js 24.19.0, npm 12.0.2, Pi 0.85.1, Linux ARM64.
- `npm run build` и `npm run typecheck` — успешно.
- `npm test` — 12 проверок, 12 успешно. Используется `--liftoff-only` для ограничения памяти компилятора WASM.
- Настоящий npm-архив устанавливается через `pi install npm:@dev-sergeev/datalab-kit` из локального реестра в отдельный каталог агента.
- Все восемь компонентов загружаются без ошибок; реальные модели GigaChat зарегистрированы. Авторизация и запросы к модели без учётных данных не проверялись.
- Чтение внутри и вне проекта, чистые shell-команды и безопасный localhost curl не запрашивают подтверждения.
- Изменения файлов, rm/hadoop/hdfs, удалённый curl, изменяющий localhost curl и составные изменяющие команды запрашивают подтверждение.
- Enter отменяет; ↓ + Enter разрешает один запуск; повторный вызов снова спрашивает.
- Пользовательские разрешения, универсальное правило, настройки диалога, текущая модель и настройки субагентов сохраняются и имеют приоритет.
- Некорректный глобальный конфиг не включает разрешающие значения набора.
- Лимит одного проверен на настоящем manager для background, foreground и resume с управляемыми дочерними сессиями.
- Обычная активация не устанавливает появившуюся новую GigaChat. После первой активации штатное `pi update --extensions` обновляет её при неизменной версии набора.

## Остаётся

- **Неполное соответствие спецификации:** штатное обновление до первой активации не гарантирует новую GigaChat из-за ограничения установщика Pi 0.85.1. Интеграционный тест фиксирует этот случай; см. issue 01 и ADR 0002.
- macOS добавлена в матрицу CI, но в текущей Linux-среде не запускалась. До результата CI совместимость macOS не подтверждена.
- Публикация в npm не выполнялась.

Ревью по двум направлениям и исправления записаны в [review.md](review.md). Открытое требование не превращено в исключение из спецификации.
