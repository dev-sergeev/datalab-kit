## Standards

Документированных нарушений правил репозитория не обнаружено.

Первоначальные замечания:

1. Эвристика остаточного кода: адаптация оставляла неиспользуемую `upstreamPermissionDecision`.
2. Эвристика дублирования: изоляция и очистка сессии повторялись в двух test helpers.
3. P1: `sort --compress-program` мог запустить изменяющую программу без подтверждения.
4. P2: README ссылался на ADR, который отсутствовал в публикуемом архиве.

Исправления: исходный диалог теперь вызывается при явных пользовательских настройках, общая изоляция вынесена в helper, опасные параметры sort требуют подтверждения, ADR включены в архив. Повторная проверка не выявила новых конкретных дефектов.

Итого: 2 эвристики и 2 ошибки устранены. Открытых замечаний этого направления нет.

## Spec

Первоначальные замечания:

1. P1: независимое обновление GigaChat до первой активации не обеспечено из-за сохранения кешированного списка пакетов установщиком Pi.
2. P1: исходный лимит субагентов действовал только для фоновых запусков; foreground и resume его обходили.
3. P1: раскрытие glob (`find . *` при наличии файла `-delete`) и `sort --compress-program` позволяли изменять данные без подтверждения.

Исправления: общий scheduler охватывает background, foreground, RPC и resume; проверка использует настоящий manager с управляемыми дочерними сессиями. Парсер требует подтверждения для раскрытия glob и опасных параметров sort. Явные пользовательские настройки диалога сохраняют приоритет. Повторная проверка подтвердила исправления и не выявила новых конкретных дефектов. Существенного расширения объёма задачи не обнаружено.

Итого: из 3 замечаний 2 устранены. Открытое P1 — обновление GigaChat до первого запуска Pi; см. [задачу](issues/01-pi-install-lifecycle-registration.md). Требование остаётся обязательным и не считается полностью реализованным.
