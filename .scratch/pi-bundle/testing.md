# Проверки реализации

Публичные границы проверок определены согласованными критериями приёмки в spec.md: команда установки и результат загрузки Pi; решения разрешений для вызовов инструментов; клавиши диалога подтверждения; работа субагентов; стандартная команда обновления.

Изменение способа объединения конфигов или устройства парсера не должно менять эти проверки. Первые проверки выполняются на Linux с отдельным PI_CODING_AGENT_DIR; пользовательские файлы Pi и учётные данные не используются. Для macOS предназначен отдельный запуск CI.
