# Проверка дополнительных расширений

Дата: 2026-10-02. Среда: macOS, Node.js 26.3.0, Pi 0.85.1; локально разрешён `pi-gigachat` 0.4.0. Реальные пользовательские конфиги и общие навыки не изменялись.

## Результаты

- `npm run build` — успешно; в recap адаптируется только встроенная default-модель, таймаут сохранён. Elapsed, toggle-skills и mention-skill не адаптируются.
- `npm run typecheck` — успешно.
- Новые интеграционные проверки — 12/12 в составе полного набора; регрессия сброса `Use default` отдельно прошла после исправления.
- `node --liftoff-only --test test/installation.test.mjs` — установка настоящего архива через штатный Pi и независимое обновление GigaChat прошли.
- `npm test` — итоговый полный набор после исправления найденного при ревью сброса default: 49/49, 0 пропущенных, около 29 секунд.
- Двухосевое ревью — Standards: 0 замечаний; Spec: 0 оставшихся замечаний, первоначальный P2 исправлен. Подробности в `review.md`.

## Поведение

- Pi загружает 12 компонентов без ошибок; фиксированные расширения включены в npm-архив с зависимостями, API хоста не включены.
- Recap создаёт штатный конфиг с Qwen, если выбор модели отсутствует; другие поля сохраняются. Явная модель и некорректный конфиг не перезаписываются при запуске и `/reload`.
- Настоящая команда `/recap` через локальный HTTP endpoint отправляет `model: Qwen3.5-397b`, `reasoning_effort: off`, получает резюме и показывает widget. Основная модель GLM и уровень reasoning `high` сохраняются. Выбранная пользователем модель recap GLM также работает.
- Сброс через настоящий picker `/recap config` → `Use default` в той же сессии возвращает Qwen; следующий `/recap` без `/reload` использует Qwen/off, сохраняя основную модель GLM.
- Elapsed считает полный TUI-запуск через несколько шагов и инструментов, очищается после окончания и shutdown, обнуляется на следующем запросе; в RPC не запускается.
- Штатный интерфейс `/toggle-skills` изменяет только тестовый `SKILL.md`. После `/reload` навык скрывается из system prompt; `$` autocomplete и фактическое раскрытие навыка перед HTTP-запросом продолжают работать. Slash autocomplete скрывает навыки и сохраняет другие команды.

## Проверяемые причины

Первый тест загрузки падал с `8 !== 12`; после явного включения новых ресурсов и bundled dependencies проходит. Тест конфигурации recap сначала падал из-за отсутствующего конфига, после инициализации проходит.

Обновление mutable-зависимости GigaChat до 0.4.0 выявило смену основной модели через standalone session-start handler. При bootstrap внутри набора регистрируется публичный экспорт провайдера, без этого обработчика. Проверки сохранения основной модели проходят. Самостоятельно загруженный GigaChat сохраняет собственную политику выбора основной модели; ограничение описано в README.

Spec-ревью выявило возврат hardcoded OpenAI после `Use default`. Регрессионный тест сначала падал через реальные команды Pi. Подстановка provider/id в `DEFAULT_RECAP_MODEL` исправила причину: после сброса Qwen выбирается сразу, и picker показывает правильный default. Нужда в `/reload` не используется как обход проблемы.

## Пределы

HTTP-проверки используют только localhost и синтетический токен. Реальный Qwen endpoint, качество его резюме и укладывание реальной генерации в 4 секунды не проверены. Штатный таймаут расширения сохранён; конфиг и `GIGACHAT_TIMEOUT` его не увеличивают.

Версия пакета не повышалась, публикация npm и push не выполнялись; изменения находятся в Unreleased. Предсуществовавшее изменение пользовательского `TODO` не включается в коммит.
