# Подключение GigaChat из окружения

Требования и архитектура согласованы; реализация разрешена. Решение зафиксировано в [ADR 0003](../../docs/adr/0003-datalab-environment-provider.md).

- Использовать pi-gigachat 0.6.1 без изменения его кода.
- Datalab Kit добавляет подключение с фиксированным набором моделей: `glm-5.2` (контекст 200000, максимальный вывод 64000 токенов) и `Qwen3.5-397b` (контекст 262144, максимальный вывод 32768 токенов). Reasoning maps сохраняются как у соответствующих моделей в upstream 0.5.1.
- Имя и идентификатор провайдера — `DataLab`. В штатном `/model` модели отображаются как `glm-5.2 [DataLab]` и `Qwen3.5-397b [DataLab]`. Model ID передаются серверу без изменений.
- При загрузке расширения Datalab Kit проверяет непустые после trim значения `GIGACHAT_API_URL` и `JPY_API_TOKEN` в окружении процесса Pi. Только при наличии обоих значений автоматически регистрируются провайдер `DataLab` и обе модели.
- Добавление моделей не меняет текущую модель или сохранённые defaults пользователя.
- Состав моделей задаёт Datalab Kit, а не пользовательское окружение или каталог сервера.
- Окружение пользователя — постоянный источник адреса сервера и токена доступа.
- Адрес API задаётся переменной `GIGACHAT_API_URL`, токен доступа — `JPY_API_TOKEN`.
- `GIGACHAT_API_URL` содержит корень API, включая необходимый серверу префикс пути (например, `/v1`), без `/chat/completions`. Суффикс `/chat/completions` добавляет адаптер.
- Токен передаётся в запросе как `Authorization: Bearer …` и не сохраняется в `auth.json` или других настройках.
- Если хотя бы одна из переменных отсутствует, пуста или содержит только пробелы, провайдер `DataLab` и его модели не регистрируются и не появляются в `/model`. Сетевые запросы при этом не выполняются.
- Регистрация не проверяет сервер и не выполняет пробных генераций. При обращении пользователя к модели выполняется настоящий запрос с заданными URL и токеном; ошибки сервера возвращаются пользователю.
- Переменные должны быть заданы до запуска Pi; Datalab Kit не загружает `.env` автоматически. После изменения окружения и перезапуска Pi используются новые значения.

Штатный `/gigachat` в 0.6.1 — интерактивный мастер, не интерфейс настройки через аргументы. Он сохраняется без автоматизации и изменения исходников upstream, как и пользовательские настройки и подключения. Datalab Kit регистрирует отдельный нативный провайдер `DataLab`, повторно используя публичный stream/adapter upstream, а не добавляя подключение через мастер. Ограничение ADR 0002 на собственную политику моделей пересмотрено только для дополнительного DataLab; поведение штатного upstream остаётся неизменным.
