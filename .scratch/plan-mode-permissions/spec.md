# Разрешения в Plan mode

Пользователь согласовал разделение политик: Plan mode самостоятельно определяет допустимые операции; дополнительные правила Datalab Kit применяются вне Plan mode. Явные пользовательские правила сохраняют приоритет согласно ADR 0001.

## Требования

- В активном Plan mode слой значений по умолчанию Datalab Kit не требует подтверждений. Инструменты планирования также не вызывают дополнительные диалоги набора.
- Проверка pi-plan-mode сохраняется: запрещённые им инструменты и команды блокируются до запроса разрешений.
- Пользовательские `ask`/`deny` в глобальной, проектной и агентской конфигурациях продолжают проверяться, в том числе для частей составной команды и путей.
- Некорректная пользовательская конфигурация сохраняет существующее поведение fail closed.
- Выход из Plan mode и переход к реализации немедленно восстанавливают обычную политику; вне Plan mode поведение не меняется.
- Состояние определяется для текущей ветки текущей сессии. Восстановление, смена ветки и независимые сессии не должны оставлять устаревшие разрешения.

## Реализация

Plan mode загружается перед permission-system. Адаптация pi-plan-mode предоставляет синхронную проверку активности через шину событий Pi: режим включён, владеет workflow и относится к запрошенной сессии. Адаптация permission-system выбирает нижний слой политики по этому состоянию. Кеш разделён по режимам; пользовательские слои остаются выше. Синтетические запросы permission-system с происхождением `builtin` делегируются Plan mode только при корректных пользовательских конфигурациях.

Проверка активности адаптирует закреплённую версию pi-plan-mode 0.58.3. Сборка проверяет её версию и единственность места изменения, а интеграционные тесты проверяют переключение и восстановление режима вместе с permission-system. Сохранённое состояние само по себе не отключает правила набора, если расширение plan-mode не загружено или восстановление workflow не удалось. Субагент использует состояние собственной сессии.

Plan mode не является строгой гарантией отсутствия записи: допустимые тесты могут создавать артефакты. Расширение его политики не входит в задачу.
