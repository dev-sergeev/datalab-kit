# Пользовательские настройки имеют приоритет

Datalab Kit поставляет настройки как значения по умолчанию, а уже заданные пользователем значения имеют приоритет, включая правила разрешений и предел числа субагентов. Выбрали этот подход вместо обязательного применения политики набора, чтобы установка готового набора дополняла конфигурацию пользователя и сохраняла его явные решения. Следствие: настройки набора не являются неизменяемыми ограничениями и могут быть переопределены пользователем.
