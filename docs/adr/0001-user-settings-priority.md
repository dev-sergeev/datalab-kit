# Пользовательские настройки имеют приоритет

Применимость: историческое решение для значений по умолчанию Kit 0.1.x. С 0.2.1 Kit не задаёт собственных разрешений, лимитов субагентов или моделей; их поведение определяется самостоятельными пакетами. Сохранность пользовательских источников, pins, фильтров и настроек при установке остаётся требованием [ADR 0004](0004-independent-component-installer.md).

Datalab Kit поставляет настройки как значения по умолчанию, а уже заданные пользователем значения имеют приоритет, включая правила разрешений и предел числа субагентов. Выбрали этот подход вместо обязательного применения политики набора, чтобы установка готового набора дополняла конфигурацию пользователя и сохраняла его явные решения. Следствие: настройки набора не являются неизменяемыми ограничениями и могут быть переопределены пользователем.

Уточнение от 2026-10-12: приоритет относится к значениям, задаваемым самим Datalab Kit. Набор сохраняет штатное поведение `pi-gigachat`, включая собственное назначение модели по умолчанию этим пакетом; он может менять сохранённые настройки основной модели по своей политике. Datalab Kit не добавляет отдельного назначения модели и не очищает существующие конфиги recap или авторизацию.
