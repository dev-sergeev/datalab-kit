# Доменная документация

Перед изучением предметной области прочитайте `CONTEXT.md` в корне проекта и относящиеся к задаче ADR из `docs/adr/`. Если этих файлов пока нет, продолжайте работу. Навык `/domain-modeling` создаёт их по мере появления согласованных терминов и решений.

## Структура

В проекте используется схема single-context:

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

Используйте термины из `CONTEXT.md` в задачах, предложениях, гипотезах и тестах. Если нужного термина там нет, проверьте употребление в проекте и при необходимости зафиксируйте пробел для `/domain-modeling`.

Если предлагаемое решение противоречит существующему ADR, явно укажите противоречие и причину пересмотра.
