# Метки triage

Навыки используют пять ролей triage. В этом проекте строка метки совпадает с названием роли.

| Роль | Метка | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется оценка сопровождающего |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача описана достаточно для агента |
| `ready-for-human` | `ready-for-human` | Задачу должен выполнить человек |
| `wontfix` | `wontfix` | Задача не будет выполняться |

Когда навык называет роль, используйте соответствующую строку метки из таблицы. Для локальных задач записывайте её в строке `Status:`.
