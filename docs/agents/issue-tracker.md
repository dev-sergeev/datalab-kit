# Трекер задач: локальные Markdown-файлы

Задачи и спецификации проекта хранятся в `.scratch/`.

## Соглашения

- Одна функциональность — одна папка: `.scratch/<feature-slug>/`.
- Спецификация: `.scratch/<feature-slug>/spec.md`.
- Каждая задача — отдельный файл `.scratch/<feature-slug>/issues/<NN>-<slug>.md`. Нумерация начинается с `01`.
- Состояние triage записывается строкой `Status:` в начале файла задачи; значения описаны в `triage-labels.md`.
- Комментарии добавляются в конце файла под заголовком `## Comments`.

## Публикация и чтение задач

Если навык просит опубликовать задачу, создайте файл в соответствующей папке `.scratch/<feature-slug>/`. Если он просит получить задачу, прочитайте файл по указанному пути или номеру.

## Карта задач

Для `/wayfinder` карта находится в `.scratch/<effort>/map.md`, а дочерние задачи — в `.scratch/<effort>/issues/NN-<slug>.md`.

- Тип задачи записывается строкой `Type:` (`research`, `prototype`, `grilling` или `task`).
- Рабочее состояние записывается строкой `Status:` (`claimed` или `resolved`).
- Зависимости записываются строкой `Blocked by: NN, NN`. Задача доступна, когда все указанные задачи имеют состояние `resolved`.
- Следующую задачу выбирают среди открытых, незаблокированных и не занятых файлов по порядку номеров.
- Перед началом работы установите `Status: claimed` и сохраните файл.
- После завершения добавьте ответ под заголовком `## Answer`, установите `Status: resolved` и добавьте краткую запись со ссылкой в раздел Decisions-so-far файла `map.md`.
